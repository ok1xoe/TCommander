# macTC

Nativní macOS správce souborů inspirovaný Total Commanderem. Swift 6, SwiftUI + AppKit, Swift Package.

```bash
swift build          # build
swift test           # testy
swift run macTC      # spuštění
scripts/bundle.sh    # složí dist/macTC.app
```

Návrh a fáze: [docs/spec.md](docs/spec.md). Evidence spotřeby tokenů: [docs/token-ledger.md](docs/token-ledger.md).
