# Panels, Tabs and Navigation

## Moving around

- **Return** on a folder opens it; **Backspace** (or the ".." entry) goes up.
- The **◀ ▶** buttons next to the path field go back and forward in the history of that panel; **▲** goes up.
- Type a path into the path field. Folders you visited recently are in the **History** menu.
- The **drives bar** has Home, Desktop, Downloads, Applications and all mounted disks. If it is too wide for the panel, scroll arrows appear at its edges; you can also scroll it with the mouse wheel.
- **Page Up / Page Down / Home / End** move the cursor by a page or to the first or last item.

## View modes

Choose the mode from the **View** menu:

| Mode | Shows |
|---|---|
| **Full** | a table with name, extension, size, date and attributes (columns are configurable) |
| **Brief** | names in columns, many files at once |
| **Thumbnails** | previews of images, documents and videos |
| **Tree** | a folder tree next to the file list |

**Quick View** shows a preview of the file under the cursor in the other panel. **Branch view** lists the files of all subfolders in one flat list. **Show hidden files** is in the View menu and in Settings.

Click a column heading to sort; click again to reverse. You can show other columns, such as image size, audio length, or PDF pages, and keep several column layouts; see [Customizing](10-customizing.html#columns).

## Tabs

Every panel can have many tabs, each with its own folder and history.

- **⌘T** opens a new tab, **⌘W** closes it, **Ctrl+Tab** switches to the next one.
- **Lock** a tab so that it always stays on one folder (opening a subfolder then opens a new tab).
- Hold the right mouse button on a folder to open it in a new tab.
- **Save tab set…** in the Tabs menu stores all your tabs under a name; choose it later to bring the layout back.

When there are more tabs than fit, the row scrolls with arrows at its ends.

## Favorites (hotlist) and history

The **Favorites** menu holds folders you use often. Add the current folder with **⌘D**, remove folders with *Remove*. The **History** menu lists recently visited folders.

## Layout

*View ▸ Panels stacked / side by side* switches between left-right and top-bottom layouts. **Swap panels** exchanges the two panels; **Target = source** shows the same folder in both.

## Folder sizes

Press **Space** on a folder to mark it and calculate its size; **Mark ▸ Calculate folder sizes** does it for the whole panel.
