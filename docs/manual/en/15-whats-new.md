# What's New

## Version 1.0.0

The first release. TCommander is a two-panel file manager for macOS, available as a free download from GitHub and on the Mac App Store.

- **Two panels with tabs**: history, favorites, and four view modes (full, brief, thumbnails, tree), plus Quick View.
- **Viewer and editor** with syntax highlighting in 25+ languages, hex view, images, PDF, audio, video and a built-in Markdown reader.
- **Search** by name, content, regular expression, hex, date, size and attributes, also inside archives.
- **Compare and synchronize** files and folders, with a preview before anything changes.
- **Multi-Rename**, checksums, duplicate finder, file splitting and joining.
- **Archives as folders**: zip, tar, 7z (read and write), rar, iso and cab (read).
- **Network**: FTP, FTPS, SMB, WebDAV, and SFTP in the GitHub edition.
- **Terminal** that runs full-screen programs such as vim and top.
- **Customization**: every shortcut, the button bar, the Start menu and the main menu; import from Total Commander.
- **Plugins** in any language (GitHub edition), with ten working examples.
- **English and Czech** interface, and this built-in user guide.
- **Two editions**: the GitHub edition with full disk access and the Mac App Store edition in the App Sandbox. See [Mac App Store Edition](13-app-store-edition.html).
