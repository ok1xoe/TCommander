# TCommander User Guide

TCommander is a two-panel file manager for macOS in the tradition of Norton Commander and Total Commander. Two folders side by side, everything on the keyboard, fast file operations and a lot of built-in tools: a viewer and editor with syntax highlighting, search, comparison and synchronization, archives as folders, FTP and network shares, a terminal and more.

## Where to start

- **New here?** Read [Getting Started](01-getting-started.html): the main window, the function keys and your first copy.
- **Coming from Total Commander?** Most keys are the same (F3 view, F4 edit, F5 copy, F6 move, F7 new folder, F8 delete, Alt+F7 find, Tab switches the panel). You can even [import your `wincmd.ini`](10-customizing.html#import-from-total-commander).
- **Looking for a key?** See [Keyboard Shortcuts](12-shortcuts.html) or search this guide with the box at the top left.

## Two editions

TCommander comes in two editions with the same core. The **Mac App Store edition** runs in Apple's App Sandbox, which means you grant it access to folders once (see [Mac App Store Edition](13-app-store-edition.html)), and a few features that need to run other programs are not included. The **GitHub edition** (a free download of the same app) has full disk access and also offers SFTP, plugins and PlantUML diagrams. This guide marks features that are only in one edition.
