# Terminal and Command Line

## The command line

The line under the panels works in the folder of the active panel.

- Type a **shell command** and press Return to run it; the output is shown in a window.
- **`cd path`** changes the folder of the active panel (`cd ~` goes home).
- **Ctrl+Return** inserts the name of the file under the cursor into the command line.

## Built-in terminal

*Tools ▸ Terminal* (**⌥⌘T**) opens a terminal window in the current folder. It runs your login shell (zsh by default) and supports colors, **full-screen programs** such as `vim`, `less`, `top` and `htop`, window resizing, copy and paste, and several windows at once. **Ctrl+C** interrupts the running program. Mouse reporting and double-width (CJK) characters are not supported.

You can also run commands with a button, a Start menu entry or a shortcut; see [Customizing](10-customizing.html#user-commands).
