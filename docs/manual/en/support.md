# Support

Need help with TCommander? Start here. Most questions are answered in the [User Guide](index.html) (use the search box at the top), and the quick answers below cover the most common ones.

## Get help

- **Report a bug or ask a question:** open an issue at [github.com/ok1xoe/TCommander/issues](https://github.com/ok1xoe/TCommander/issues). You need a free GitHub account.
- **Suggest a feature:** open an issue the same way and describe what you would like to do.
- **Source code and releases:** [github.com/ok1xoe/TCommander](https://github.com/ok1xoe/TCommander).

To help me find the problem quickly, please include:

1. your TCommander version (the About window) and the edition (GitHub or Mac App Store),
2. your macOS version and whether the Mac is Apple silicon or Intel,
3. what you did, what you expected and what happened instead; a screenshot helps.

TCommander has no accounts, analytics or tracking, so it never sends me any information. Please do not include passwords or private file contents in a report. See the [Privacy Policy](privacy.html).

## Quick answers

**TCommander asks which folder it may use.** This is the macOS App Sandbox in the Mac App Store edition. In the welcome dialog choose *Whole disk* and confirm with *Allow Access*; you are asked only once. Choose *Only my home folder* if you prefer a narrower permission. Details: [Mac App Store Edition](13-app-store-edition.html).

**A folder shows "access denied" or looks empty.** macOS protects some places (for example Documents, Desktop, Downloads or a removable disk) and asks once for each. If you refused, allow TCommander again in *System Settings ▸ Privacy & Security ▸ Files and Folders* or *Full Disk Access* (GitHub edition). In the App Store edition open the folder in a panel and allow it in the dialog.

**macOS says the app cannot be opened (GitHub edition).** Right-click the app, choose *Open* and confirm once.

**SFTP, plugins or PlantUML diagrams are missing.** They are available only in the GitHub edition, because Apple's rules do not allow them in the Mac App Store edition. See the comparison in [Mac App Store Edition](13-app-store-edition.html).

**How do I change a keyboard shortcut?** *Settings ▸ Shortcuts*. The defaults are listed in [Keyboard Shortcuts](12-shortcuts.html).

**Can I use my Total Commander settings?** Yes, import your `wincmd.ini` with *Tools ▸ Import settings from Total Commander…*. Most keys are the same.

**Which macOS versions are supported?** macOS 14 Sonoma and later, on Apple silicon and Intel Macs.
