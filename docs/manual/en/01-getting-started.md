# Getting Started

## The main window

The window is split into two **panels**. Each panel shows one folder. Above each panel you see, from top to bottom:

- the **path field**: click it, type a path and press Return to go there;
- the **drives bar**: Home, Desktop, Downloads, Applications and every mounted disk;
- the **tabs**: each panel can hold many folders (see [Panels, Tabs and Navigation](02-panels-and-tabs.html)).

At the very top there is the **button bar** and the **Start menu** (both are yours to customize), at the bottom the **command line** and the row of **function keys** F2 to F8.

One panel is always **active** (a colored line on its top edge). Press **Tab** to switch. Most operations take the files in the active panel (the *source*) and the folder in the other panel (the *target*).

## The five keys you need

| Key | Does | Notes |
|---|---|---|
| **F3** | View | opens the Lister: text, images, PDF, hex, Markdown and more |
| **F4** | Edit | built-in editor with syntax highlighting |
| **F5** | Copy | to the folder in the other panel |
| **F6** | Move | to the folder in the other panel |
| **F8** | Delete | to the Trash (Shift+F8 deletes permanently) |

Also useful: **F7** creates a folder, **F2** renames, **Alt+F7** searches, **Space** or **Insert** marks a file, **Return** opens a folder or file, **Backspace** goes up one level.

## Your first copy

1. In the left panel go to the folder that contains your files.
2. In the right panel go to the folder you want to copy to (type the path, or use the drives bar).
3. Move the cursor with the arrow keys onto a file and press **Space** to mark it. Mark more if you like.
4. Press **F5**. A dialog confirms the target; press Return.
5. A progress bar appears at the bottom. Copies run in a **queue**, so you can keep working. You can pause or cancel any job.

If a file already exists in the target you are asked what to do: overwrite, skip, rename, keep both, overwrite only older files, or apply the answer to all.

## Mouse and trackpad

Everything also works with the mouse: click to select, double-click to open, drag files between the panels, or from and to Finder. Hold the **right mouse button** on a folder for a moment to be offered to open it in a **new tab**.
